# 전화번호 입력받아서 문자 보내기

macOS에서 여러 전화번호에 같은 내용을 보내기 위한 로컬 도구 모음입니다. 웹앱으로 작성창을 열 수 있고, CLI로는 Messages 앱을 순차 자동 조작해 한 번에 발송할 수 있습니다.

## 웹앱 실행

```bash
npm start
```

브라우저에서 `http://127.0.0.1:3000` 으로 접속합니다.

## CLI 일괄 발송 실행

```bash
python3 send_bulk_sms.py --to "01012345678,01098765432" --message "안녕하세요. 테스트 문자입니다."
```

더 짧게는:

```bash
./send_sms.sh "01012345678,01098765432" "안녕하세요. 테스트 문자입니다."
```

가장 짧게는:

```bash
./sms "01012345678,01098765432" "안녕하세요. 테스트 문자입니다."
```

또는 파일로 줄 수 있습니다.

```bash
python3 send_bulk_sms.py --recipients-file recipients.txt --message "안녕하세요. 테스트 문자입니다."
```

`recipients.txt` 예시:

```text
01012345678
01098765432
01055554444
```

실제 발송 전 확인만 하고 싶으면:

```bash
python3 send_bulk_sms.py --recipients-file recipients.txt --message "안녕하세요." --dry-run
```

## 동작 방식

- 입력한 값으로 `sms:` 링크를 만듭니다.
- 수신자는 줄바꿈이나 쉼표로 구분해서 최대 20명까지 입력할 수 있습니다.
- macOS `sms:` 링크는 다중 수신자를 안정적으로 처리하지 못할 수 있어, 여러 명일 때는 같은 문구로 작성창을 한 명씩 순서대로 엽니다.
- 브라우저가 macOS Messages 앱으로 넘겨 작성 창을 엽니다.
- 실제 SMS 발송은 Mac과 iPhone의 문자 메시지 전달 설정 상태에 따라 달라집니다.
- CLI는 각 수신자별 `sms:` 작성창을 연 뒤 Messages의 보내기 동작을 UI 자동화로 실행합니다.

## 로컬 전용 보안 설정

- 서버는 `127.0.0.1` 에만 바인딩됩니다.
- 외부 네트워크 호출을 하지 않습니다.
- `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options` 같은 기본 보안 헤더를 적용했습니다.
- `GET`, `HEAD` 외 요청 메서드는 막습니다.

## 사용 전 주의

- 본인이 발송할 권한이 있고 사전에 수신 동의를 받은 번호에만 사용하세요.
- CLI 자동 발송은 별도의 마지막 확인 단계 없이 순차 전송하므로, 먼저 `--dry-run`과 한 명의 테스트 수신자로 확인하세요.
- 기본 발송 로그에는 수신자 전화번호가 기록됩니다. `sms_send.log`와 수신자 목록 파일은 Git에서 제외되며, 필요가 끝난 기록은 안전하게 정리하세요.
- 통신사 정책, 관련 법률과 메시지 플랫폼의 이용 조건을 준수할 책임은 사용자에게 있습니다.

## 참고

- 전화번호는 숫자, `+`, `-`, 공백 위주로 입력하는 것이 안전합니다.
- 메시지 앱이 바로 열리지 않으면 `SMS 링크 복사` 버튼으로 링크를 복사해 직접 실행할 수 있습니다.
- CLI 자동 발송은 macOS `시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용`과 `자동화` 권한이 필요할 수 있습니다.
- Messages의 `Return 키로 메시지 보내기` 설정이나 UI 언어가 다르면 보내기 버튼 탐지가 달라질 수 있어, 첫 실행은 1명으로 테스트하는 편이 안전합니다.
